## Этап 1 — v1.0.3+4: багфиксы (S, безопасно для сейвов)

Все изменения аддитивны к схеме сейва: старые сохранения читаются через `?? default`.

1. **Klondike: сброс `_usedUndo`** в `newGame()` / `build()` / `startDailyChallenge()`.
   Сейчас после первого undo в жизни приложения достижение `achv_no_undo` и
   испытания `noUndo` всегда проваливаются. (klondike_controller.dart)
2. **FreeCell: подсказки без русского текста из движка** — `hint()` возвращает
   машинные теги (как Klondike/Spider), перевод в `AppStrings` на экране.
   EN-пользователи сейчас видят русские подсказки. (freecell_engine.dart)
3. **Хардкод-строки → AppStrings**: «персональные настройки» и «Скоро: эффекты
   и анимации» (style_screen), «Нет доступных ходов» (freecell_screen).
4. **Spider: `suitCount` в сейв** (`SpiderPersistence` + восстановление в
   `build()`), иначе победа в 2/4 масти после перезапуска пишется как 1 масть.
5. **Persistence: убрать `orElse: () => spades`** — на битом сейве бросать
   исключение → `null` → новая игра (вместо молчаливых дублей карт).
   Все 3 persistence-файла.
6. **Guard `mounted`** в `selector_screen._navigateToGame` (context через
   async-разрыв, уже в ворнингах линтера).
7. Проверить `destroy()` у `RewardedAdLoader` в yandex_rewarded.dart (утечка).

Регресс: RU/EN на всех экранах · сейв со старой версии продолжает партию ·
daily для всех 3 режимов · победа/undo/hint в каждом режиме.

## Этап 2 — v1.1.0+5: чистота и порядок (M, поведение не меняется)

Цель — единая точка для каждого визуала/логики, чтобы правки не размножались.

1. **`shared/widgets/playing_card_view.dart`** — один виджет карты
   (classic/minimal, ранг, масть, рубашка). Заменяет 4 копии:
   `_playingCard` в klondike_screen, `_playingCard` в spider_screen,
   инлайн-рендер в freecell_screen, превью в style_screen.
2. **Drag-preview в контроллеры** — убрать `KlondikeEngine()`/`SpiderEngine()`
   из экранов: контроллер получает `previewDropTo...()`-методы, экран только
   рендерит и вызывает. `_state`-геттер с `asData!.value` заменить на
   безопасное чтение.
3. **Базовый класс/mixin контроллеров** — undo/redo, бюджет отмен, подсказки,
   rewarded-гранты, `_apply` (сейчас ~120 строк × 3 копии).
4. **Протокол подсказок: `sealed class Hint`** вместо строковых тегов
   (`waste_to_tableau_3` и парсинг через RegExp в spider autoFinish).
   Компилятор начнёт проверять полноту обработки.
5. **WinCelebration**: `AnimatedBuilder` вокруг `CustomPaint` вместо
   `setState` на каждый кадр (сейчас перестраивается весь оверлей 60 fps).
6. **Мелочи порядка**: ключи LocalStore в один блок; метод `clearSavedGame()`
   вместо `saveKlondikeState({})` в селекторе; `_DragPayload.suitName` →
   `CardSuit`; `_cardScale` из build в локальную переменную.
7. **Большие экраны** — разрезать по смыслу там, где это упрощает правки
   (доска/панели/диалоги в отдельные файлы), без гонки за количеством строк.

После этапа: `flutter analyze` 0 замечаний в `lib/`, тесты зелёные,
ручной прогон drag&drop в 3 режимах.

## Процесс каждого релиза

1. Ветка → правки этапа → `flutter analyze` (0 warnings в lib/) → `flutter test`.
2. Регресс-чеклист этапа вручную на Android-устройстве.
3. `CHANGELOG.md` + bump `pubspec.yaml` версии → коммит → тег `vX.Y.Z`
   (release-воркфлоу соберёт APK/AAB автоматически).
4. Для этапов 1–2: поставить сборку на 1–2 устройства и убедиться, что
   партия со старого сейва продолжается (не «Новая игра»).

# ASO: тексты листинга Google Play

> Лимиты Play: заголовок ≤30 символов, краткое описание ≤80, полное ≤4000.
> Ключевые слова живут только в заголовке/описаниях (отдельного поля ключей у Play нет).
> Честность: реклама в приложении есть (баннер + при открытии + rewarded) — слово
> «без рекламы» в текстах не используем; «offline» — правда.

Куда вставлять: Play Console → Рост → Ресурсы магазина → Основной листинг →
«Управление переводами» → «Добавить переводы самостоятельно» → выбрать языки →
вставить Заголовок / Краткое описание / Полное описание.

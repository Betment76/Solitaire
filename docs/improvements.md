# План улучшений

## 🔜 Режим испытаний (Challenge Mode)

Система достижений с прогрессией:

- 5–10 испытаний: «Собери Косынку < 120 ходов», «Победи в Пауке с 4 мастями», «FreeCell без ячеек» и т.п.
- За каждое испытание — эксклюзивная рубашка карт или особый фон стола
- Прогресс хранится локально
- Иконка-трофей на экране выбора режима
- Всплывашка «🔓 Разблокировано!» при открытии нового стиля
- Примерный объём: ~200–250 строк (новый провайдер + экран + сторедж)

# Solitaire

Кроссплатформенная офлайн-игра с карточными пасьянсами на Flutter.

## Текущий статус

Проект находится в стадии подготовки к релизу MVP.

Режимы:
- ✅ **Klondike (Косынка)** — Riverpod контроллер, drag&drop, tap-to-move, undo/redo, автозавершение, подсказки, сохранение/восстановление партии.
- ✅ **Spider (Паук, 1 масть)** — Riverpod контроллер, drag&drop, undo/redo, раздача из стока, сохранение/восстановление партии.
- ✅ **FreeCell (Свободная ячейка)** — Riverpod контроллер, drag&drop, undo/redo, сохранение/восстановление партии.

Системные экраны:
- ✅ Выбор режима
- ✅ Настройки (язык, тема, звук, вибрация, рубашка карт)
- ✅ Статистика (общие показатели + победы по режимам, миграция старых сохранений)
- 🟡 Заглушки и будущие экраны сохраняются и будут постепенно заменяться полноценными реализациями.

Все 3 режима полностью рефакторены: UI отделён от логики через Riverpod контроллеры.

## Стек

- Flutter / Dart
- Riverpod (`flutter_riverpod`)
- Локальное хранилище: `shared_preferences`
- Локализация: RU/EN (`flutter_localizations` + `AppStrings`)

## Локализация

Поддерживаются языки:
- Русский (`ru`)
- Английский (`en`)

Язык по умолчанию берётся из системы; можно изменить вручную в настройках.

## Данные и сохранение

Локально сохраняются:
- настройки приложения;
- статистика;
- состояние текущей партии.

Хранение реализовано через `SharedPreferences`.
